## Elio Planner
Aplikasi kalender dan planner ringan di folder [`planner/`](planner/).
Buka di https://melkiyunus05.github.io/planner/ lalu "Install" / "Add to Home Screen" supaya jadi aplikasi.

- Kalender bulanan, klik tanggal untuk lihat dan tambah item
- Kategori: to do, deadline (tugas, lomba, presentasi, asistensi, rapat, ujian), jadwal kuliah, asistensi, acara, pengumuman
- Jadwal berulang tiap minggu (untuk kuliah dan asistensi)
- Tab "Mendatang" berisi hitung mundur H-n untuk 14 hari ke depan
- Data tersimpan di perangkat (localStorage), bisa ekspor/impor backup JSON
- Bisa dipakai offline
