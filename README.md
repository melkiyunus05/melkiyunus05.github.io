## Elio Planner
Aplikasi kalender dan planner ringan di folder [`planner/`](planner/).
Buka di https://melkiyunus05.github.io/planner/ lalu "Install" / "Add to Home Screen" supaya jadi aplikasi.

- Tiga tampilan: Hari (jadwal, tugas, dan Fokus hari ini), Minggu (timetable), dan Bulan
- Sub-tugas dengan progress, tanda penting, dan Fokus hari ini (maksimal 3)
- To-do harian dan Rencana kerja yang dicicil beberapa hari (sesi per hari, input cepat gaya catatan WA: `Modul 3 TP: Sen 1, Sel 1, Rab 2`), dengan batas beban harian dan pindahan to-do kemarin
- Jam harian berbentuk jam dinding (dua cincin 12 jam) dengan agenda, slot kosong, dan atur sesi otomatis
- Pengingat (selama aplikasi terbuka atau berjalan di latar belakang)
- Halaman Mata Kuliah: jadwal, tugas/ujian, kalkulator nilai (skala UI) dan target, IP perkiraan, link, catatan
- Timer fokus (Pomodoro) yang terhubung ke tugas dan matkul, dengan statistik harian, mingguan, dan per matkul
- Pelacak Lomba: tahap Incar, Persiapan, Menunggu hasil, Selesai; tanggal penting otomatis masuk kalender; checklist berkas
- Kategori bisa diatur sendiri lewat menu "Kelola kategori" (nama, warna, urutan, jenis). Bawaan: to do, deadline, ujian, jadwal kuliah, asistensi, acara, pengumuman
- Jadwal berulang tiap minggu (untuk kuliah dan asistensi)
- Tab "Mendatang" berisi hitung mundur H-n untuk 14 hari ke depan
- File (PDF, dokumen, gambar) yang dilampirkan ke tugas, matkul, dan lomba, dikelompokkan per jenis yang bisa diatur sendiri
- Sinkronisasi laptop dan tablet lewat Supabase (gratis). Panduan pengaturan: [planner/SETUP-CLOUD.md](planner/SETUP-CLOUD.md)
- Data juga tersimpan di perangkat (bisa offline), plus ekspor/impor backup JSON
- Bisa dipakai offline
